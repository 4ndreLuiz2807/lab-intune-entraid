## Como uso isso

1. Leio o capítulo/projeto correspondente no material de referência.
2. Preencho a seção **"Minhas anotações"** de cada arquivo com o que entendi, nas minhas palavras — não é cópia do texto original.
3. Quando aplico algo na prática no laboratório, viro um [registro](../../registros) completo e linko aqui.
